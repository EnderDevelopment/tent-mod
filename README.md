# Tent Mod

A Fabric mod that adds a tent block to Minecraft, allowing players to place and interact with tents in the game world.

## Features

- Adds a tent block to the game
- Tent block has an occupied state property

## Requirements

- Minecraft 1.21.4
- Fabric Loader 0.15.11 or later

## Installation

1. Download the mod JAR file from the [releases page](https://github.com/EnderDevelopment/tent-mod/releases)
2. Place the JAR file in your Minecraft mods folder
3. Launch Minecraft with Fabric Loader installed

## Usage

- Craft or obtain a tent item
- Place the tent block in the world
- Interact with the tent block to change its occupied state

## Configuration

The mod does not have any configuration files. All settings are hardcoded in the mod.
